# Interactive Scientific & Currency Calculator Engine

المشروع التطبيقي الأول لمسار توثيق JavaScript الشامل (Phase 03: Operators and Expressions).

---

## 1. نظرة عامة على المشروع (Project Overview)

محرك آلة حاسبة علمية ومحول عملات مبني بلغة TypeScript ومصمم ليكون تطبيقا عمليا هندسيا لكافة المفاهيم المشروحة في المرحلة الثالثة من توثيق JavaScript (الدروس من 13 إلى 17):
- المعاملات الحسابية وكائن `Math` (الدرس 13).
- معاملات الإسناد والمقارنة (الدرس 14).
- المعاملات المنطقية والتقييم ذو الدارة القصيرة (الدرس 15).
- المعاملات البتية والمعاملات المتنوعة (الدرس 16).
- أسبقية المعاملات وقواعد التجميع وخوارزمية Shunting-Yard (الدرس 17).

---

## 2. المعمارية البرمجية (Software Architecture)

تم تقسيم المشروع وفق مبدأ فصل الاهتمامات (Separation of Concerns) إلى ثلاث طبقات رئيسية:

### أ. محرك الحساب الرياضي (`CalculatorEngine.ts`)
- **Lexical Analysis (Tokenization):** تحليل السلسلة النصية المدخلة إلى رموز برمجية (`tokens`) تشمل الأرقام، المعاملات، الدوال العلمية، والأقواس مع دعم الإشارات السالبة المسبقة (Unary Negation).
- **Shunting-Yard Algorithm:** تحويل التعبيرات من الصيغة الداخلية (Infix Notation) إلى الصيغة البولندية العكسية (Reverse Polish Notation - RPN) من تصميم عالم الحاسوب Edsger Dijkstra.
- **Precedence & Associativity Table:** جدول أسبقية دقيق يدعم التجميع من اليسار إلى اليمين (Left-Associative) للمعاملات الأساسية، ومن اليمين إلى اليسار (Right-Associative) لمعامل الأسس (`^` أو `**`).
- **RPN Evaluator:** تنفيذ التعبير المحول عبر مكدس (Stack) ومعالجة الدوال الرياضية المثلثية (`sin`, `cos`, `tan`) واللوغاريتمية (`log`, `ln`) والجذر التربيعي والقيمة المطلقة.
- **IEEE 754 Precision Cleanup:** التخلص من أخطاء الفاصلة العائمة المعتادة (مثل `0.1 + 0.2 = 0.30000000000000004`) عبر خوارزمية تقريب ذكية مبنية على دقة الآلة (`Number.EPSILON`).

### ب. محول العملات التعليمي (`CurrencyConverter.ts`)
- **Reference Exchange Rates:** قاعدة بيانات مرجعية موثقة لثماني عملات عالمية وإقليمية رئيسية منسوبة إلى الدولار الأمريكي (USD).
- **إخلاء مسؤولية توثيقي:** أسعار الصرف المدرجة في هذا المحول هي بيانات مرجعية تعليمية ثابتة وموثقة لأغراض الشرح الهندسي والتطبيقي، ولا تمثل بثا حيا فوريا لأسواق المال.
- **Integer Scaling & Cent Math:** إجراء العمليات الحسابية المالية بعد تحويل القيم إلى أعداد صحيحة لتفادي فقدان الدقة في الحسابات النقدية.
- **Intl.NumberFormat Integration:** تنسيق المخرجات المالية وفق المعايير الدولية لكل عملة محلية.

### ج. واجهة المستخدم التفاعلية (`ScientificCalculator.tsx`)
- مكون React تفاعلي كامل يدعم الوضعين: الآلة الحاسبة العلمية، ومحول العملات.
- سجل عمليات تفاعلي (Calculation History Stack).
- سجل ذاكرة مخصص (`M+`, `M-`, `MR`, `MC`).
- دعم التبديل بين نظام الدرجات (Degrees) والراديان (Radians).
- دعم كامل لإمكانية الوصول (Accessibility) ولوحة المفاتيح.

## 3. تطبيق مفاهيم المرحلة الثالثة في الكود

| المفهوم النظري | التطبيق العملي في المحرك |
|---|---|
| **Arithmetic Operators** | تنفيذ العمليات الأساسية الجمع، الطرح، الضرب، القسمة، باقي القسمة، والأسس في مكدس RPN. |
| **Math Object** | استخدام `Math.sin`, `Math.cos`, `Math.tan`, `Math.sqrt`, `Math.log10`, `Math.log`, `Math.abs`, الثوابت `Math.PI` و `Math.E`. |
| **Operator Precedence** | مصفوفة أسبقية تحدد متى يتم تفريغ المعاملات من المكدس ومتى يتم تأجيلها أثناء التحويل. |
| **Associativity** | التمييز بين الأسس `^` (Right-to-Left) والمعاملات الحسابية الأخرى `+`, `-`, `*`, `/` (Left-to-Right). |
| **Short-Circuit Evaluation** | استخدام `??` و `||` و `&&` في معالجة المدخلات والقيم الافتراضية والتحقق من الأخطاء. |
| **Comparison Operators** | التحقق الدقيق من الحدود الرياضية مثل القسمة على الصفر أو لوغاريتم الأرقام السالبة. |
