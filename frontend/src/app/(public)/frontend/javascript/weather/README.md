# مشروع 05: تطبيق حالة الطقس المباشر
## Project 05: Live Weather Application

### نظرة عامة (Overview)
تطبيق طقس حي ومتكامل يعرض بيانات الطقس اللحظية والتوقعات الجوية لأي مدينة في العالم، مع دعم التحديد الجغرافي التلقائي عبر Geolocation API.

### المفاهيم البرمجية المطبقة (Implemented Concepts)
- **طلبات الشبكة عبر Fetch API:** إرسال واستقبال بيانات JSON مع معالجة الترويسات (Headers).
- **التدفق اللاتزامني (Async/Await):** كتابة أكواد غير متزامنة نظيفة ومنظمة.
- **معالجة أخطاء الشبكة والاستجابة:** التعامل مع فحص `response.ok` ورموز الاستجابة (404, 500) وحالات فقدان الاتصال.
- **واجهة تحديد الموقع الجغرافي (Geolocation API):** الحصول على إحداثيات خطوط الطول والعرض بموافقة المستخدم.
- **تنسيق درجات الحرارة والوحدات:** التحويل بين مئوية وفهرنهايت وتنسيق الوقت المحلي.

### المسار المباشر (Direct Route)
`/frontend/javascript/weather`

### طريقة الاستخدام والتشغيل
اكتب اسم المدينة في شريط البحث أو اضغط على زر تحديد الموقع الحالي لعرض الطقس اللحظي والتوقعات.
