# مشروع 04: تطبيق الاختبارات التفاعلي
## Project 04: Interactive Quiz Engine

### نظرة عامة (Overview)
محرك اختبارات برمجية تفاعلي يختبر مهارات المطورين في JavaScript، مزود بمؤقت زمني ديناميكي، تقييم فوري، وتوليد عشوائي لترتيب الأسئلة والإجابات.

### المفاهيم البرمجية المطبقة (Implemented Concepts)
- **المؤقتات الزمنية اللاتزامنية:** استخدام `setInterval` و `clearInterval` لإدارة التوقيت والتنقل التلقائي عند انتهاء الوقت.
- **خلط المصفوفات (Fisher-Yates Shuffle):** خوارزمية عشوائية لإعادة ترتيب الخيارات بدون تكرار أو انحياز.
- **إدارة النقاط والنسب المئوية:** حساب النتيجة النهائية بدقة وعرض تقرير الأداء.
- **كائنات وهياكل بيانات الأسئلة:** تمثيل غني للأسئلة مع شروحات تعليمية للخيارات الصحيحة والخاطئة.
- **إعادة تشغيل ومراجعة الإجابات:** استعراض الأخطاء والتعلم منها مع شروحات معمارية.

### المسار المباشر (Direct Route)
`/frontend/javascript/quiz`

### طريقة الاستخدام والتشغيل
ابدأ الاختبار من خلال الضغط على زر بدء الاختبار، واختر إجابتك قبل انتهاء المؤقت التنازلي.
