# مشروع 06: متتبع المصروفات والميزانية الشخصية
## Project 06: Personal Expense & Budget Tracker

### نظرة عامة (Overview)
تطبيق مالي لإدارة ومتابعة المصروفات والمداخيل، وتصنيف المعاملات وتوليد تقارير بيانية تفاعلية لحساب الرصيد الصافي ومعدلات الإنفاق.

### المفاهيم البرمجية المطبقة (Implemented Concepts)
- **التجميع الحسابي بدالة reduce:** حساب إجمالي الدخل والمصروفات وصافي الرصيد بكفاءة $O(n)$.
- **تنسيق العملات الدولية (Intl.NumberFormat):** عرض الأرقام المالية وفق العملات المحلية والدولية تلقائيًا.
- **تصفية وبحث المعاملات:** فلترة المعاملات حسب التصنيف، النطاق الزمني، والنوع.
- **التخزين الدائم بـ LocalStorage:** حفظ كافة السجلات وتحديثها بدون فقدان أي بيانات.
- **تصور البيانات والنسب المئوية:** حساب النسب المئوية لكل فئة من المصروفات ورسم مؤشرات بصرية.

### المسار المباشر (Direct Route)
`/frontend/javascript/expense-tracker`

### طريقة الاستخدام والتشغيل
أضف المعاملة بتحديد العنوان والمبلغ والنوع والتصنيف لتظهر فورًا في جدول المعاملات وتنعكس على مؤشرات الميزانية.
