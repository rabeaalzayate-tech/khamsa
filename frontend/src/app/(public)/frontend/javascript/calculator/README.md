# مشروع 01: محرك الآلة الحاسبة العلمية ومحول العملات التفاعلي
## Project 01: Interactive Scientific & Currency Calculator Engine

### نظرة عامة (Overview)
محرك حسابي متقدم يحاكي الآلات الحاسبة العلمية الحديثة، مصمم لتطبيق مفاهيم المعاملات الحسابية، أسبقية المعاملات (Operator Precedence)، والتحويل الضمني والصريح للأنواع في JavaScript.

### المفاهيم البرمجية المطبقة (Implemented Concepts)
- **تقييم التعبيرات الرياضية:** معالجة العمليات الحسابية المتتالية مع احترام ترتيب الأسبقية.
- **كائن الرياضيات (Math Object):** استخدام الدوال المثلثية، الجذور التربيعية، الأسس، واللوغاريتمات.
- **التحويلات العددية الدقيقة:** معالجة مشكلات الفاصلة العائمة (Floating Point Arithmetic) عبر `Number.EPSILON` ودوال التقريب.
- **التحويل بين العملات:** إدارة أسعار الصرف الحية والتحويل المالي المباشر.
- **إدارة الحالة التفاعلية:** واجهة React/Next.js تفاعلية مبنية بـ Tailwind CSS بدون أي مكتبات خارجية للحساب.

### المسار المباشر (Direct Route)
`/frontend/javascript/calculator`

### طريقة الاستخدام والتشغيل
المشروع مدمج بالكامل داخل بيئة Next.js كصفحة عميل (`use client`) ويتم تحميله تلقائيًا عند تصفح المسار.
