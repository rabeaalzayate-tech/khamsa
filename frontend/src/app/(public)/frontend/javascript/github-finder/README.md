# مشروع 08: باحث حسابات ومستودعات GitHub
## Project 08: GitHub Profile & Repository Finder

### نظرة عامة (Overview)
أداة بحث سريعة للتنقيب في حسابات مطوري GitHub واستعراض إحصائياتهم ومستودعاتهم البرمجية وأبرز اللغات المستخدمة، مدعمة بتقنيات تحسين الأداء.

### المفاهيم البرمجية المطبقة (Implemented Concepts)
- **تقنية تأخير الإدخال (Debouncing):** منع إرسال طلبات متكررة أثناء كتابة المستخدم لاسم الحساب لتوفير استهلاك الـ API.
- **إلغاء الطلبات المتزامنة (AbortController):** إلغاء أي طلب شبكة معلق عند بدء بحث جديد لتجنب Race Conditions.
- **التعامل مع معدلات الطلب (Rate Limits):** فحص ترويسات GitHub API وتقديم تنبيهات عند تجاوز الحد المسموح.
- **معالجة البيانات والترتيب:** فرز المستودعات حسب عدد النجوم وتاريخ آخر تحديث.
- **واجهة مستخدم متقدمة:** بطاقات تعريفية بالمستخدم ومستودعاته ومؤشرات التفاعل.

### المسار المباشر (Direct Route)
`/frontend/javascript/github-finder`

### طريقة الاستخدام والتشغيل
اكتب أي اسم مستخدم على GitHub في حقل البحث، وسيقوم التطبيق بالبحث التلقائي وعرض الملف الشخصي وأهم المستودعات فورًا.
