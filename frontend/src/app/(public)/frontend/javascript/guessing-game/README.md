# مشروع 02: لعبة تخمين الأرقام وخوارزمية البحث الثنائي
## Project 02: Number Guessing Game & Binary Search Algorithm

### نظرة عامة (Overview)
لعبة تفاعلية لتخمين الأرقام العشوائية تتيح للاعب التنافس مع الذكاء الاصطناعي الذي يطبق خوارزمية البحث الثنائي (Binary Search) للوصول إلى الرقم الصحيح في أقل عدد ممكن من الخطوات.

### المفاهيم البرمجية المطبقة (Implemented Concepts)
- **توليد الأرقام العشوائية:** `Math.random` و `Math.floor` وتوليد نطاقات عددية محددة.
- **خوارزمية البحث الثنائي (Binary Search):** حساب المتوسط `Math.floor((min + max) / 2)` وتقليص فضاء البحث لوغاريتميًا $O(\log n)$.
- **إدارة المحاولات وسجل الحركات:** تتبع مسار اللعب ومصفوفات تاريخ التخمينات.
- **الجمل الشرطية والتحكم في التدفق:** معالجة حالات الفوز، التوجيه (أكبر/أصغر)، ونفاد المحاولات.
- **التصميم المتجاوب والتفاعلي:** واجهة مستخدم توفر ملاحظات فورية وحركات بصرية بالـ CSS.
