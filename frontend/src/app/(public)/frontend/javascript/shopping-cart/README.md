# مشروع 07: سلة تسوق متكاملة لمتجر إلكتروني
## Project 07: E-commerce Shopping Cart

### نظرة عامة (Overview)
محرك سلة تسوق تجارية متقدم يحاكي منصات التجارة الإلكترونية الكبرى، يدعم إضافة المنتجات، تعديل الكميات، تطبيق كوبونات الخصم، وحساب الضرائب والشحن تلقائيًا.

### المفاهيم البرمجية المطبقة (Implemented Concepts)
- **هياكل بيانات Map و Set:** تخزين المنتجات والكميات وضمان عدم تكرار المعرفات الفريدة.
- **التحديث غير القابل للتعديل (Immutability):** تعديل بنية السلة عبر نسخ الكائنات والمصفوفات بدون تطفل.
- **محرك الكوبونات والخصومات:** التحقق من صلاحية الكوبونات وتطبيق نسب الخصم أو المبالغ الثابتة.
- **حساب الضرائب وتكاليف الشحن:** خوارزميات حسابية متعددة الخطوات تراعي الحدود الدنيا للشحن المجاني.
- **استمرارية السلة (Cart Persistence):** مزامنة محتويات السلة في التخزين المحلي لاسترجاعها عند العودة للموقع.

### المسار المباشر (Direct Route)
`/frontend/javascript/shopping-cart`

### طريقة الاستخدام والتشغيل
تصفح المنتجات المتوفرة، أضفها إلى السلة، وجرب إدخال كوبون خصم لحساب المجموع الإجمالي والضريبة تلقائيًا.
